# Modular Model Rocket 🚀

A small, modular model rocket designed primarily for **C6-5 rocket motors**, with a design that allows for easy adaptation to different motor sizes.

## Overview

This project is a compact model rocket designed with modularity and ease of use in mind. Its main purpose is to provide a simple, reusable rocket platform that can be adapted to accommodate different motor sizes without having to redesign or rebuild the entire rocket.

The rocket is designed around the **C6-5 motor** as its primary configuration. However, its modular construction makes it possible to modify or replace individual components to support other compatible motor sizes.

## Features

- **Modular design:** Individual components can be modified, replaced, or upgraded independently.
- **Interchangeable motor compatibility:** Designed to make adapting the rocket to different motor sizes straightforward.
- **Compact design:** Small overall size, intended for lightweight model rocket flights.
- **Reusable construction:** Designed to be recovered and flown multiple times, subject to inspection and maintenance.
- **Easy to modify:** The modular architecture makes experimentation and future improvements easier.

## Motor Compatibility

The rocket is primarily designed for use with:

| Motor | Intended use |
|---|---|
| C6-5 | Primary motor configuration |

The modular motor mount is intended to make adapting the rocket to other motor sizes easier.
